# 小可 Wiki 页面结构

## 1. 概念/架构页

```text
# 标题

本文将会介绍……。

## 介绍
这页解决什么问题；涉及哪些组件。

## 代码结构 / 组成
目录树或组件表；表后写“说明：”。

## 运行流程
### 入站 / 出站 / 启动 / 关闭
按实际顺序分节；每节先一句总述，再列步骤。

## 边界与异常
退出码、超时、重试、限制；用表格或列表。

## 相关
只放确实需要的站内链接。
```

## 2. 教程/开发页

```text
# 标题

本文将会教你……。阅读前需要……

## 介绍
模块/适配器是什么；运行期由谁加载。

## 目录结构
目录树；说明必要文件和可选文件。

## 最小实例
最小可运行代码；说明每段的作用。

## 创建 / 声明
### 注册模块
### 注册命令
### 命令语法模板
参数、模式、返回值逐条说明。

## 功能扩展
### 正则与定时任务
### Hook 与事件
### 配置、数据库与本地化

## 验证与排错
如何运行、看日志、重载；常见失败原因。
```

## 3. 模块使用页

```text
# 模块名

此模块可以……。

## 命令名
公开 / 仅管理员 / 仅超级用户

用法：`~命令 ...`

选项：
- `-x`：……

此命令用于……。

说明：
- 参数规则
- 结果规则
- 失败条件

示例：
（ChatExample）

## 其他命令
按命令重复上面的结构。
```

单命令模块可以合并为：

```text
# 模块名
此模块可以……。

## 用法
权限、CommandUsage、参数、示例。

## 结果
成功时返回什么；不同输入如何分流。

## 限制
数量、权限、平台、配置上限。
```
