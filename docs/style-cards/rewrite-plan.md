## 每页改写规则

1. 从 HEAD 原内容出发，不在已改文本上叠加。
2. 先写一句“本文将会教你/介绍/整理……”，说明读者能获得什么。
3. H2 用名词或动宾短语，按主题或命令拆分；不写问句标题。
4. 一段 1–3 句。长分号句拆成短句或列表。
5. 代码块前用“示例：”或“以下为……”，代码块后用“说明：”。
6. 模块页写“用法：”“选项：”；教程页按步骤推进；参考页按对象/方法组织。
7. 结尾停在最后一个技术点，不写空泛的收尾。

## 保护清单

- front matter、H1、站内链接、图注。
- `CommandUsage`、`ChatExample`、`NoticeBox` 等组件的属性与内容。
- 代码块、命令、路径、URL、版本号、数字、默认值。
- 表格数据与行数。
- 示例对话原文。

只改叙述。需要修正事实时，先查源码或配置；查不到就保留原文并标注。
