# 24 点

随机给出四个 1 到 13 的整数，要求用加、减、乘、除与括号使结果为 24。也可以先判断组合是否无解，或直接查询全部解。

模块名 `twenty-four`，别名 `twenty_four`、`twentyfour`、`24`。

## 安装

```bash
akaribot module add akari-bot-module-twenty_four
```

安装后在会话中由管理员用 `module enable twenty-four` 开启。

## 命令

下表省略命令前缀，前缀由实例配置决定。

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `twenty-four` | 开始新游戏 | 所有用户 |
| `twenty-four stop` | 结束当前游戏 | 所有用户 |
| `twenty-four solve <num1> <num2> <num3> <num4>` | 列出四个数字的全部解，非超级用户消耗 4 花瓣 | 所有用户 |

游戏规则：

- 每个数字必须且只能使用一次，只允许四则运算与括号。
- 回答表达式后按结果是否为 24 判定；表达式不合法时返回无效提示。
- 组合无解时可以回答「无解」「無解」「none」「n/a」「na」「n.a.」之一。
- 判定无解且确实无解时奖励 1 花瓣；判定无解但存在解时扣除 1 花瓣并给出其中一组解；回答正确时奖励 1 花瓣。
- 花瓣增减仅在实例开启花瓣系统时生效。

`solve` 要求四个数字均在 1 到 13 之间，存在进行中的对局时拒绝执行；非超级用户需支付 4 花瓣，未开启花瓣系统时不扣除，余额不足时终止。存在解时逐条列出，不存在解时返回无解提示。

游戏状态按会话保存在进程内，1 小时后自动过期；服务重启后状态丢失。
