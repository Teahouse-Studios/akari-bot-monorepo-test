# coin

抛掷一枚或多枚硬币，结果分为正面、反面与立起三种，按权重抽取。

## 命令

### `coin`

<CommandUsage usage="coin [<amount>]" :params="['amount=抛掷的硬币枚数，省略时为 1']" permission="public" />

- 抛掷指定枚数的硬币，省略枚数时抛 1 枚。
- 枚数为 0 时返回未抛掷的提示。
- 枚数为负数或超过单次上限时返回范围错误；上限由管理员配置。
- 单枚结果单独播报。
- 全部同面时汇报总数；出现多种结果时分别统计正面、反面与立起的数量。
