# coin

此模块可以抛掷一枚或多枚硬币。每次抛掷的结果为正面、反面或立起，各结果的概率由配置的权重决定。

## 命令

### `coin`

<CommandUsage usage="coin [<amount>]" :params="['amount=抛掷的硬币枚数，省略时为 1']" permission="public" />

说明：

- `amount` 为 `0` 时返回“你抛了个空气，什么也没发生……”。
- `amount` 小于 `0` 时返回“无效的硬币数量”。
- `amount` 大于单次上限时返回“你最多只能抛 N 枚硬币”，上限由管理员配置。
- 只抛 1 枚时，直接返回这一枚的结果。
- 全部硬币结果相同时，返回总枚数和这一结果。
- 出现多种结果时，分别统计正面、反面和立起的数量。
