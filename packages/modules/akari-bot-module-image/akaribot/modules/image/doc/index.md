# 图片处理

把透明背景的图片填充为白色背景。处理对象取自消息中的图片；当前消息不含图片时，机器人先提示发送图片，再等待下一条消息。

## 安装

```bash
akaribot module add akari-bot-module-image
```

模块名为 `image`，命令前缀为 `image`，没有别名。

## 命令

| 命令 | 说明 |
| --- | --- |
| `image fillwhite ...` | 将消息中的透明背景图片填充为白色背景 |

命令模板接受任意附加文本，处理对象只来自消息中的图片元素。多张图片时按序号逐张输出；不含透明通道的图片不转换，单独给出提示。整条消息没有任何图片时返回未找到图片并中止。

## 配置项

无。本包没有 `config.py`，`manifest.toml` 也未声明配置表。

## 权限与平台能力

- 模块声明 `required_superuser=True`，仅机器人超级用户可执行。
- 未声明平台限制，所有已接入平台可用。
- 平台需支持接收与发送图片：输入依赖消息中的图片元素，输出为转换后的图片。

## 数据表

无。图片只在内存中转换，不落库。

## 依赖与外部服务

- 运行依赖：`akari-bot-core`、`Pillow>=13.0.0,<13.1.0`。
- 不访问外部服务。
