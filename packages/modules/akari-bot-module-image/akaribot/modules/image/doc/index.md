# image

此模块把透明背景的图片填充为白色背景，处理对象取自当前消息。当前消息不含图片时，机器人先提示发送图片，再等待下一条消息。

## 命令

### `image fillwhite`

<CommandUsage usage="image fillwhite ..." permission="superuser" />

此命令用于把当前消息中的透明背景图片填充为白色背景。

说明：

- 命令模板接受任意附加文本，但只处理当前消息里的图片元素。
- 多张图片按序号逐张输出。
- 不含透明通道的图片不转换，单独给出提示。
- 等待期间仍没有图片时，机器人提示未找到图片并中止。
