# image

此模块将包含透明背景的图片填充为白色背景，处理对象来源于当前消息。若当前消息未包含图片，机器人先提示发送图片，再等待接收下一条消息。

## 命令

### `image fillwhite`

<CommandUsage usage="image fillwhite ..." permission="superuser" />

此命令用于将当前消息中包含透明背景的图片填充为白色背景。

说明：

- 命令模板接受任意附加文本，但仅处理当前消息中的图片元素。
- 多张图片按照序号逐张输出。
- 未包含透明通道的图片不执行转换，单独返回提示信息。
- 若等待期间仍未接收到图片，机器人将提示未找到图片并终止操作。
