# nbnhhsh

查询一句含有拼音首字母缩写的话，返回站点收录的候选含义。适用于「yyds」「xswl」一类网络缩写。

模块名 `nbnhhsh`，没有别名。

## 命令

下表省略命令前缀，前缀由实例配置决定。

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `nbnhhsh <term>` | 查询文本中的拼音首字母缩写含义 | 所有用户 |

返回内容以输入文本的小写形式开头，随后是匹配结果：

- 站点提供确定释义时，直接列出各条释义，以顿号分隔。
- 站点只提供候选输入时，以「有可能是：」开头列出候选释义。
- 没有匹配结果时返回未找到提示。

返回释义在发送前会经过内容审核，不合规内容会被替换为脱敏标记。
