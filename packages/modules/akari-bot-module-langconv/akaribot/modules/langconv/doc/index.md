# 简繁转换

在简体中文、繁体（香港）与繁体（台湾）之间转换文本，转换由 langconv 库完成。

## 安装

```bash
akaribot module add akari-bot-module-langconv
```

模块名为 `langconv`，命令前缀为 `langconv`，别名为 `lc`。

## 命令

| 命令 | 说明 |
| --- | --- |
| `langconv <language> <content>` | 把文本转换为指定目标语言 |

`<language>` 接受 `zh-cn`、`zh-hk`、`zh-tw`，也可省略 `zh` 前缀直接写 `cn`、`hk`、`tw`。参数会统一转小写并把下划线替换为连字符，因此 `zh_cn`、`zh_TW` 等写法同样可用。目标语言不在支持范围内时返回不支持提示。

`<content>` 为待转换文本，转换结果直接作为消息正文返回。

## 配置项

无。本包没有 `config.py`，`manifest.toml` 也未声明配置表。

## 权限与平台能力

- 命令对普通用户开放，不要求管理员或超级用户权限。
- 未声明平台限制，所有已接入平台可用。
- 未声明支持语言；转换目标由命令参数决定，与会话语言无关。
- 三个转换器在首次使用时惰性加载，之后进程内复用。

## 数据表

无。转换结果不落库。

## 依赖与外部服务

- 运行依赖：`akari-bot-core`、`langconv==0.4.0`。
- 不访问外部服务，转换在进程内完成。
