# whois

向域名的 WHOIS 服务器查询注册信息，按可用字段逐项展示域名名称、注册商、日期、DNS 服务器、邮箱、注册人与位置。

模块名 `whois`，没有别名。

## 命令

下表省略命令前缀，前缀由实例配置决定。

| 命令 | 说明 | 权限 |
| --- | --- | --- |
| `whois <domain>` | 查询域名的 WHOIS 信息 | 所有用户 |

返回字段：

| 字段 | 说明 |
| --- | --- |
| 域名名称 | 查询结果中的域名，统一转为小写 |
| 注册商 | 域名注册商 |
| WHOIS 服务器 | 应答查询的 WHOIS 服务器，统一转为小写 |
| 更新日期 | 记录最后更新时间，按会话时区格式化 |
| 注册日期 | 域名首次注册时间，按会话时区格式化 |
| 截止日期 | 域名到期时间，按会话时区格式化 |
| DNS 服务器 | 名称服务器列表，去重后以小写逗号分隔 |
| 邮箱 | 注册人邮箱，去重后展示 |
| DNSSEC | DNSSEC 状态 |
| 名称 | 注册人名称 |
| 组织 | 注册人组织 |
| 位置 | 由地址、城市、州或省、国家拼接 |
| 邮编 | 注册人邮政编码 |

日期字段在接口返回列表时取第一项，并按 UTC 解释后转换。任一字段缺失时跳过该项；域名名称为空或查询抛出异常时返回获取失败提示。
