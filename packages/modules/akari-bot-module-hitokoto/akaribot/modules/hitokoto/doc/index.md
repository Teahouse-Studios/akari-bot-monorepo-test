# hitokoto

从一言 API 获取随机句子，可指定句子类型。返回内容包含句子正文、作者与出处，并附一言主页链接；繁体中文会话下正文与出处自动转换为繁体。

## 命令

| 命令 | 说明 |
| --- | --- |
| `hitokoto` | 随机获取一条一言 |
| `hitokoto <msg_type>` | 获取指定类型的一言 |

### `hitokoto`

随机获取一条一言，返回句子正文、作者、出处与一言主页链接；繁体中文会话下正文与出处自动转换。

### `hitokoto <msg_type>`

按类型代码 `a` 至 `l` 获取指定类型的一言。代码含义由一言 API 定义，模块内只校验取值范围，
不在范围内时返回无效类型提示；类型代码作为 API 的 `c` 参数传递。
