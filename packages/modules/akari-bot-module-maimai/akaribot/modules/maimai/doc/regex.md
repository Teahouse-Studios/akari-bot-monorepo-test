# 正则句式

`maimai-regex` 模块（别名 `maimai_regex`、`mai_regex`）不注册命令前缀，直接匹配聊天消息中的自然语言句式，并复用 `maimai` 模块的查询逻辑。该模块推荐与 `maimai` 模块一同启用；正则模块要求平台允许机器人读取全部消息。

模块声明支持 `zh_cn` 与 `zh_tw`，句式中的常用字同时接受简体与繁体写法，例如「什么／什麼」「进度／進度」。所有句式对普通用户开放。

<NoticeBox type="info">
曲目信息、别名、随机歌曲与段位资料来自本地曲目库、别名库和包内资料，不要求账号。成绩、进度与名牌板句式会读取玩家当前选择的数据源，必须先绑定水鱼（<code>maimai bind df</code>）或落雪（<code>maimai bind lx</code>）账号。水鱼侧需要实例配置 OAuth 应用。
</NoticeBox>

| 句式示例 | 查询内容 | 数据源 | 账号 |
| --- | --- | --- | --- |
| `834是什么歌` | 歌曲信息 | 本地曲目库、别名库 | 不需要 |
| `id834有什么别名` | 歌曲别名 | 本地别名库 | 不需要 |
| `id834有什么分` | 单曲成绩 | 所选数据源 | 需要绑定 |
| `14+ SSS+进度` | 等级评价进度 | 所选数据源 | 需要绑定 |
| `14+ SSS+完成表` | 等级评价完成表 | 所选数据源 | 需要绑定 |
| `舞神进度` | 名牌板进度 | 所选数据源 | 需要绑定 |
| `舞神完成表` | 名牌板完成表 | 所选数据源 | 需要绑定 |
| `随个dx紫14+` | 条件随机歌曲 | 本地曲目库 | 不需要 |
| `十段段位表` | 段位认定列表 | 包内段位资料 | 不需要 |

## 曲目与别名

**`<ID 或别名>是什么歌`**：查询歌曲的艺术家、分类、BPM、版本与难度。名称以 `id` 开头时按 ID 解析，其余按歌名或别名解析；命中多个别名时返回候选 ID 列表。示例：`834是什么歌`、`id834是什么歌`、`PANDORA PARADOXXX是什么歌`。

**`<ID>有什么别名`**：查询歌曲的别名列表，ID 可带 `id` 前缀。别名库由 `maimai update` 更新；文件不存在时会提示先执行更新。示例：`834有什么别名`、`id834有什麼別名`。

<CommandUsage usage="id834是什么歌" permission="public" type="regex" :aliases="['mai_regex', 'maimai_regex']" note="按 ID 或别名查询歌曲；这一句式与 maimai song 的查询结果一致。" />

## 成绩与进度

**`<ID 或别名>有什么分`**：查询绑定账号在该曲目各难度的成绩，包括达成率、评级、连击与同步标记。ID 可带 `id` 前缀；别名命中多首时返回候选列表。该句式需要绑定当前数据源的账号，查询对象固定为绑定账号，不能指定其他玩家。

**`<等级> <目标>进度`** 与 **`<等级> <目标>完成表`**：查看绑定账号在指定等级的目标评价进度。等级取 `1` 至 `15+`，目标取 `A`、`AA`、`AAA`、`S`、`S+`、`SS`、`SS+`、`SSS`、`SSS+`、`FC`、`FC+`、`AP`、`AP+`、`SYNC`、`FS`、`FS+`、`FDX`、`FDX+`。`进度` 输出文字摘要，`完成表` 额外生成图片。示例：`14+ SSS+进度`、`14+ SSS+完成表`。

**`<名牌板>进度`** 与 **`<名牌板>完成表`**：查看绑定账号的名牌板完成情况。名牌板名按游戏内名称填写，例如 `舞神进度`、`霸者完成表`。`完成表` 输出图片形式的完成列表。

<CommandUsage usage="id834有什么分" permission="public" type="regex" :aliases="['mai_regex', 'maimai_regex']" note="成绩句式需要绑定账号；数据源为水鱼时使用水鱼授权，为落雪时使用落雪授权。" />

## 随机与段位

**`随个[dx|标准][颜色]<等级>`**：按条件随机一首歌曲。类型可写 `dx`、`sd`、`标准` 或 `標準`，省略时不筛选类型；颜色可写绿、黄、红、紫、白，省略时不筛选难度；等级必须给出，例如 `随个14+`、`随个dx紫14+`、`随个标准13`。该句式不使用 `maimai random` 的 `*` 无条件写法。

**`<段位>段位[认定][列]表`**：查询段位认定的曲目与通关条件。段位支持普通段位、真段位以及 EXPERT／MASTER 各级，例如 `十段段位表`、`真初段段位认定表`、`MASTER超上级段位列表`。数据来自包内段位资料，不访问查分器。

<CommandUsage usage="随个dx紫14+" permission="public" type="regex" :aliases="['mai_regex', 'maimai_regex']" note="类型与颜色均可省略，等级不可省略。" />

## 匹配说明

- 正则从消息开头匹配。歌名、名牌板或段位前后不要附加其他说明，例如「请问 834 是什么歌」会把「请问 834」当作歌名。
- `有什么别名` 的 ID 必须是数字，不能使用歌名或别名。
- 成绩、进度与名牌板句式只查询绑定账号，未绑定时返回对应的绑定命令；B50 不在正则范围内，使用 `maimai b50`。
- 歌名与别名匹配不区分大小写；段位句式需使用包内段位资料中的名称。

<NoticeBox type="warning">
正则句式没有命令前缀，任何匹配到的消息都会触发查询。若平台不允许读取全部消息，或不需要自然语言触发，可只启用 <code>maimai</code> 模块并使用命令形式。
</NoticeBox>
