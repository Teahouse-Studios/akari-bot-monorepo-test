# ID 表查询

查询 Minecraft：基岩版的 ID 表，按关键词检索标识符及其对应值。结果来自第三方 ID 表服务，模块本身不维护数据。

## 安装

```bash
akaribot module add akari-bot-module-idlist
```

模块名为 `idlist`，命令前缀为 `idlist`，没有别名。

## 命令

| 命令 | 说明 |
| --- | --- |
| `idlist <query>` | 按关键词查询 ID 表 |

每条结果显示为「枚举名：键 -> 值」，值只取首行。单次最多展示 5 条；命中总数超过 5 条时追加折叠提示与完整结果页链接。无命中时返回未找到提示。

搜索请求固定携带 `limit=6`，用于判断是否存在更多结果。

## 配置项

无。本包没有 `config.py`，`manifest.toml` 也未声明配置表。

## 权限与平台能力

- 命令对普通用户开放，不要求管理员或超级用户权限。
- 未声明平台限制，所有已接入平台可用。
- 声明支持语言为 `zh_cn`。
- 结果中的完整结果页以链接形式发送，平台需支持 URL 消息元素。

## 数据表

无。查询结果不落库。

## 依赖与外部服务

- 运行依赖：`akari-bot-core`。
- ID 表服务：`https://idlist.projectxero.top/search`，查询接口与结果页均来自该站点。
- 接口约定参考 caidlist 项目的 API 文档。
