# 本地化

面向用户的固定文案统一经 `I18NContext` 声明，翻译数据存放在各包的 `locales/`，运行时由
`akari-bot-i18n` 的 `Locale` 解析。默认语言为 `zh_cn`，支持的语言见 `lang_list`：简体中文、繁體中文、
English、日本語、한국어。

## I18NContext

```python
from akaribot.core.api import I18NContext

await msg.finish(I18NContext("core.message.admin.add.success", sender=user))
```

`I18NContext` 是消息元素，保存键名与参数，发送时才按会话语言翻译。可选参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `fallback` | `True` | 键缺失时回退到默认语言 |
| `locale_failed_prompt` | `True` | 翻译失败时附加提示 |
| `disable_joke` | `False` | 禁用文案中的玩笑替换 |

参数值可以是字符串、数字或其它消息元素；元素作为参数时会被转为字符串字面量。

## 键与真源

- 每个包在 `manifest.toml` 的 `locales` 声明目录（默认 `locales`），文件名为语言代码。
- 简体中文 `locales/zh_cn.json` 是唯一需要人工维护的真源；新键只在此文件建立节点。
- 运行时快照由 `build_locale_snapshot(lang_list, collect_locale_paths(), "akari-bot")` 构建，
  `collect_locale_paths()` 取自发现层，core 的目录排在最前。
- 配置字段注释使用 `config.comments.<表名>.<字段名>` 形式的键，与普通文案同文件。
- 命令模板中的帮助文案写作 `{{I18N:key}}`，由帮助系统解析。
- 术语占位符 `{TERM:...}` 由 `locales/terms/<语言>.json` 提供平台相关措辞（如「场景」「群组」）。

## 插值与占位符

模板使用 `${name}` 插值：

```json
{
  "core.message.admin.add.success": "已成功将 ${sender} 设为管理员。"
}
```

- 占位符名使用语义化英文名，与调用处关键字一一对应。
- 占位符名不得与 `t()` 的形参同名：`key`、`fallback`、`locale_failed_prompt`、`disable_joke`。
  同名会在渲染时触发 `TypeError`，例如 `${key}` 配 `key=...`。
- 修改键名或占位符后，须同时核对调用点的关键字参数。

## 语言文件维护

- 只编辑 `locales/zh_cn.json`；其它语言由 Weblate 自动提交，不手工创建、修改或补齐。
- 缺少新键时不要复制简体中文到其它语言文件，也不要自行翻译。
- `assets/config_store/<语言>/` 是配置模板派生物，非 `zh_cn` 版本同样交给自动化生成。
- 文案面向技术用户，保持书面语，不写口语或语气词。

## 会话语言

- `BaseConfig.default_locale` 是全局默认语言，实例内可用 `~setup locale <lang>` 修改场景语言。
- 会话语言保存在 `TargetUnionInfo.locale`，`msg.t` 与 `I18NContext` 都按该值解析。
- 语言文件缺失或键不存在时按 `fallback` 设置回退，并在回复中给出提示。
- `Locale.t_str(text)` 用于对已拼接的文本再做一次键替换，未命中的内容原样保留。
