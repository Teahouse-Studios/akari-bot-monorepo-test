# 终端界面

TUI 用 Textual 实现，覆盖实例的日常运维：启动与停止、模块安装、配置编辑、数据库浏览、日志跟踪、
环境管理、文档浏览与发布，以及旧项目迁移。所有写操作都经 CLI 子进程完成，界面不另存一套业务逻辑。

## 启动

```sh
akaribot            # 可交互终端下直接进界面
akaribot tui
akaribot tui --no-mouse
```

裸调用只在可交互终端进入界面；管道、重定向与 CI 环境打印帮助并以退出码 2 结束。没有实例时先询问
是否就地初始化，初始化由 `akaribot init` 的命令本体完成。

启动时把当前实例登记进注册表；站在实例之外而当前目录下只有一个实例时，登记并切换过去。当前目录
下有多个实例时只提示，不擅自选择。标题栏显示当前管理的实例名。

`--self-check` 在无终端环境下检查资源、样式表与页面交互，`--headless` 启动界面完成基础读取后退出。
两者都用于部署后的冒烟检查，未执行的检查按失败处理。

## 页面

侧栏按四组排列，`Ctrl+←` / `Ctrl+→` 按同一顺序翻页，折叠分组内的页面同样可达：

| 分组 | 页面 | 用途 |
| --- | --- | --- |
| 概览与运行 | 概览 | 实例与服务状态、实例清单、初始化摘要 |
| | 运行 | 前台/后台启停、按适配器启动、状态轮询 |
| | 日志 | 日志文件筛选、暂停与增量跟踪 |
| | 诊断 | 端口冲突、凭据重复、孤立配置 |
| 配置与平台 | 配置 | 配置表的表单与原始文本两种模式 |
| | 适配器 | 适配器实例的启停、安装与增删 |
| | 模块 | 模块安装、卸载、更新与全局装载 |
| 环境与数据 | 环境 | 解释器、已装包与运行库清单 |
| | 数据库 | 表清单、分页浏览与按主键编辑 |
| 开发与迁移 | 开发 | 工作区包清单、运行测试、生成脚手架 |
| | 文档 | 已安装包的文档浏览、构建、预览与部署 |
| | 迁移 | 旧项目迁移与预演 |

切页时焦点交给目标页，隐藏页停止轮询；页面未激活前不读取数据。

## 全局键位

| 键 | 动作 |
| --- | --- |
| `q` / `Ctrl+Q` | 退出 |
| `?` | 当前页与全局键位帮助 |
| `Ctrl+T` | 深色/浅色主题切换 |
| `Ctrl+←` / `Ctrl+→` | 上一页 / 下一页 |
| `↑` / `↓` / `Enter` | 选择页面并打开；在分组标题上按 `Enter` 或单击切换折叠 |
| `←` / `→` | 折叠所在分组 / 展开高亮的分组 |

折叠分组内的页面不显示，方向键跳过；当前页位于折叠分组内时，侧栏高亮该分组标题。折叠状态只在
本次运行内保留。

页脚只列高频键位，低频动作放在 `?` 帮助与页内按钮中，80 列下不溢出。

## 页面键位

- 概览：`r` 刷新，`Enter` 切换实例，`n` 添加实例（新建或登记目录），`Ctrl+D` 移除登记，
  `m` 服务与策略（开机自启、崩溃重启、安装或卸载服务）。
- 运行：`s` 启动，`x` 停止，`Ctrl+R` 重启，`r` 刷新，`m` 更多（按适配器启动、前台运行命令）。
- 日志：`space` 暂停跟踪，`c` 清空显示缓冲，`/` 过滤，`m` 日志级别，`r` 刷新，`Esc` 清空过滤。
- 诊断：`r` 刷新，`Enter` 打开冲突详情。
- 配置：`Ctrl+S` 保存，`o` 外部编辑器，`f` 表单模式，`t` 原始文本，`r` 刷新，`Esc` 返回表清单。
- 适配器：`r` 刷新，`i` 安装适配器，`e` 启用/停用实例，`n` 新增实例，`Ctrl+D` 移除实例。
  列表只显示已安装或已启用的适配器，未安装的平台在 `i` 打开的安装对话框中选择。
  新增实例在对话框中选择已安装的适配器并填写实例 ID，`↑` / `↓` 改选平台，`Enter` 创建。
  创建后弹出配置表单，待填写项排最前：`Enter` 下一项，`Ctrl+S` 保存，`Esc` 稍后填写。
- 模块：`r` 刷新，`/` 搜索，`i` 安装（先确认目标），`u` 卸载，`U` 更新，`e` 全局装载/卸载，
  `space` 选择，`Shift+↑/↓` 扩展选择，`a` 全选，`c` 清除选择，`Esc` 清空搜索。
- 环境：`r` 刷新，`/` 搜索，`i` 安装运行库，`u` 卸载，`m` 解释器菜单（接管 venv、交还 venv、
  重建 venv，只列当前模式可用的项），`Esc` 清空搜索。
- 数据库：`r` 刷新，`Ctrl+S` 保存，`n` 新建，`Ctrl+D` 删除，`/` 搜索，`f` 添加筛选，
  `Ctrl+F` 清空筛选，`m` 更多（排序、清空筛选），`[` / `]` 翻页，`g` / `G` 首末页。
- 开发：`r` 刷新，`t` 运行测试，`n` 新建包对话框，`o` 聚焦输出，`Esc` 终止运行中的操作。
- 文档：`r` 刷新，`/` 搜索，`space` 选择，`b` 构建，`p` 启停预览，`o` 打开浏览器，
  `m` 更多（部署、同步主题、安装依赖、任务日志），`a` 全选，`c` 清空选择。
- 迁移：`Enter` 迁移，`p` 预演。

各页按钮文字后附快捷键（如「保存 ^s」），写法与页脚一致；低频操作在 `m` 菜单中，菜单只列当前可用的项。

## 确认规则

删除、移除与清理数据的动作走 `Ctrl+<字母>` 或专用字母键（卸载为 `u`），且一律弹出模态框，
框内写明目标与影响范围：

- 删除数据项、移除适配器实例、移除实例登记、卸载模块都先确认；批量卸载要求输入目标数量。
- 「卸载并清理数据」要求输入确认文字，框内列出将删除的配置文件与数据表。
- 重建 venv 要求输入「重建」，并说明未写入清单的额外运行库需重装。
- 旧项目迁移先给出预演选项，确认框列出将传给 CLI 的参数。
- 存在未保存更改或后台任务未结束时，退出与切换实例都会先确认。

确认框打开前经 `PendingConfirm.accept(key)` 防抖：同一目标在窗口内的连发被忽略，避免叠加两层
模态。切页、刷新、换表或换选中项调用页面的 `reset_pending()` 作废待确认状态。

## 与 CLI 的写操作关系

界面的写操作统一走 `akaribot <子命令>` 子进程（冻结分发直接调用二进制），参数与确认只有命令层
一份；需要代答确认时传 `--yes`。子进程环境注入 `AKARI_INSTANCE_DIR` 和 `AKARI_CONFIG_PATH`，
输出统一按 UTF-8 解析。

读操作可以在进程内完成，但限于本机状态：注册表、锁文件、日志文件。日志页与 `akaribot logs`
共用 `akaribot/cli/logs.py` 的解析与增量读取规则；配置 schema、模块清单、数据库与体检结果都经
子进程读取。
